# 💖 Birthday Surprise Website

Flow: Heart ❤️ → Photos with music 📸 → Love message 💌 → Grand Happy Birthday 🎂

## Customize
1. Open `js/script.js` and edit the `CONFIG` block (names, captions, message).
2. Your song is at `assets/music/perfect.mp3` (replace it to change the music).
3. Replace photos in `assets/photos/` (keep names or update CONFIG).

## Host free on GitHub Pages
1. Create a new GitHub repo and upload all files (keep the folder structure).
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)` → Save.
3. Your link: `https://<username>.github.io/<repo-name>/`
